# 90-second Glass Orbit walkthrough

## Opening card — 0:00–0:10

Show the launch screen. Say: “Glass Orbit is a non-official NASA educational card game for ages 7–12, built for the 2026 NASA Space Apps Challenge: Build a Junior Astronaut Mission Trainer.”

## The room — 0:10–0:25

Start the mission. Pan subtly across the transparent glass room, Earth, Moon, Mars, and the card desk. Say: “One room keeps every consequence visible. Earth suggests supplies, the Moon a near outpost, and Mars longer waits.”

## Data card — 0:25–0:40

Open the source drawer and point to the date, speed, URL, UTC retrieval time, and SHA-256. Say: “This saved NASA DONKI observation records a CME and an analysis of 1018 kilometres per second. The orange card is an education model, not a safety forecast: in this game it raises the fictional shield target to three.”

## Decisions — 0:40–1:00

Close the drawer. Select **儲能分配**, then **輻射護盾**, then **生命維持**. Pause on each preview to show cost and effect. Let the shield ring appear after the shield card. Say: “Each card asks for a resource before it gives one back. The order creates the trade-off.”

## Evidence and result — 1:00–1:15

Open the trace and source drawer once more, then show the success result. Say: “The trace keeps the event, card, cost, and resource update visible. Observation, game inference, and children’s model are always separated.”

## Replay and close — 1:15–1:30

Press replay. Say: “A different order can create a partial result. Failure is evidence for the next strategy, not a punishment.” Show the Project Page / GitHub URL and six fallback screenshots.
