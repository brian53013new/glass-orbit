# Event Feedback Plan

| Player event | World response | State response | Reduced-motion fallback |
| --- | --- | --- | --- |
| Camera yaw | Dial arrows brighten, camera dampens to target | Tutorial advances on first turn | Immediate but bounded view change |
| Language toggle | Dial depresses and indicator changes | All text uses one locale state | No bounce / short fade |
| Terminal focus | Frame beacon brightens, camera dollies in | Tutorial waits for Escape return | Short direct move |
| Card inspect | Card lifts, moves, plaque appears | Selected card state set | Direct expand |
| Card play | Resource pillar changes and course terminal updates | Run resource/evidence/log updates | No overshoot |
| Course finish | Archive/course glow changes | Outcome + reflection stored in run log | Static completion state |
